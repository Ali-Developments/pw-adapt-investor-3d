# PW-ADAPT — Investor 3D Prototype

**Intelligent Water Treatment. Connected by Design.**

An interactive investor-facing digital twin prototype combining procedural 3D equipment exploration, dynamic process simulation, and decision-support visualization for adaptive produced-water treatment.

## Live Public Demo
[https://ali-developments.github.io/pw-adapt-investor-3d/](https://ali-developments.github.io/pw-adapt-investor-3d/)

---

## Core Capabilities
- **Procedural 3D Hardware Explorer**: Interactive bench-scale rig with 360° orbit, zoom, 6 camera presets, cutaway clipping planes, and exploded assembly views.
- **2D Process Flow Diagram & Industrial Mimic**: Real-time flow animation, valve statuses, and dynamic stream telemetry.
- **Live Simulation Engine**: Deterministic mass-balance telemetry, tank levels, and 60-second historical scrub control.
- **Fault Injection Suite**: Interactive simulation of high pressure, low flow, sensor drift, pump failure, and bypass scenarios.
- **Intelligent Decision Support**: Multi-stage adaptive treatment route evaluation (DAF, Media Filter, RO, EDI) with cost ($/m³), energy (kWh/m³), and carbon metrics.
- **Human-in-the-Loop Governance**: Operator review and digital approval workflow.

---
*Standalone client-side application engineered with React 18, TypeScript, Three.js / React Three Fiber, and Tailwind CSS.*
